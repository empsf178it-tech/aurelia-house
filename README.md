# AURELIA HOUSE — RESTAURANT WEBSITE
> **Tagline:** SLOW FOOD. BEAUTIFUL MOMENTS.

Aurelia House is a premium, cinematic multi-page restaurant website built exclusively with pure **HTML5**, **CSS3**, and **Vanilla JavaScript ES6+**.

- **Name:** AURELIA HOUSE
- **Tagline:** SLOW FOOD. BEAUTIFUL MOMENTS.

## 📄 Pages
1. **Home (`index.html`)** — Fullscreen cinematic hero, two-column story, signature dishes with hover details, horizontal ingredient gallery, dark kitchen section, dining atmosphere moments, and final CTA.
2. **Menu (`menu.html`)** — Editorial menu layout with interactive category tab filtering (Small Plates, Mains, Sides, Desserts, Botanical Drinks) without page reload.
3. **Our Kitchen (`kitchen.html`)** — 5-stage culinary process (Source → Prepare → Cook → Plate → Serve) and Executive Chef profile.
4. **Experiences (`experiences.html`)** — Bespoke dining experiences (Chef's Table, Private Dining, Seasonal Tasting, Sunday Table, Dessert Counter).
5. **About (`about.html`)** — Founder story, 3-pillar philosophy, table atmosphere, and culinary approach.
6. **Gallery (`gallery.html`)** — Masonry photography grid with category filtering and interactive fullscreen lightbox modal with keyboard controls.
7. **Reservations (`reservations.html`)** — Interactive date, time, guest selection, and contact details with instant frontend confirmation.
8. **Contact (`contact.html`)** — Address, opening hours, direct email links, and inquiry form.
9. **404 Page (`404.html`)** — Elegant restaurant-themed 404 page ("THIS TABLE ISN'T SET. But there's always another one waiting.").

## ⚡ Technical Restrictions & Standards
- **Strictly Frontend-Only:** Pure HTML5 + CSS3 + Vanilla JS (ES6+).
- **NO Frameworks/Libraries:** No React, Vue, Angular, Next.js, Bootstrap, Tailwind, jQuery, GSAP, or Three.js.
- **Custom Interaction Systems:**
  - Custom dynamic cursor with context tags ("TASTE", "EXPLORE", magnetic CTA buttons).
  - Scroll progress bar at top of viewport.
  - Intersection Observer scroll reveals & image mask reveals.
  - Page transition system.
  - Fullscreen mobile overlay menu.
  - Accessible, responsive, and performance-optimized.
